# Posts

This directory is reserved for future blog and social media post concepts in OKF format. Start from [`../templates/post-template.md`](../templates/post-template.md) so every post follows the reusable project contract.

Each post should be a Markdown concept document with YAML frontmatter and a descriptive `type`, such as `Blog Post` or `Social Media Post`. Keep `index.md` and `log.md` reserved for their OKF-defined purposes.
